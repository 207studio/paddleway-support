First connection

  1. Install Paddleway on your Mac and iPad.
  2. Open the Mac app. Use its setup buttons to sign in to Tailscale, allow Screen Recording, and allow Accessibility for keyboard and trackpad control.
  3. Open the iPad app and sign in to the same Tailscale user account. Your Macs appear automatically. Select one to connect.
  4. Keep the host Mac awake, the app running, and the network connected.

Apple silicon Mac, macOS 15+, and iPadOS 17.4+ are required. You do not need to enter a private IP address in the normal setup. Tailscale account, network policy and service plan requirements still apply.

Mac 앱의 안내 버튼에서 Tailscale 로그인, 화면 녹화, 손쉬운 사용 권한을 설정하세요. iPad에서도 같은 Tailscale 사용자로 로그인하면 Mac을 찾습니다. 평소 설정에서는 사설 IP 주소를 직접 입력하지 않습니다.

Using your workspace

  • The lower trackpad controls the Mac pointer. Use two fingers to scroll. A held finger can keep a drag active while another finger moves.
  • The keyboard button opens input on iPad. Some system shortcuts remain reserved by iPadOS.
  • The microphone button starts dictation. Recognized phrases are typed into the active Mac input field. Paddleway does not automatically press Enter.
  • The panel toggle makes the lower sky a larger trackpad. Microphone and keyboard controls remain available.
  • The pencil enables panel reordering with touch drag-and-drop.
  • The music panel uses the Apple Music system player on iPad. It does not read every other app’s Now Playing state or stream Mac audio.

If a connection drops

Check that both apps are open, the Mac is awake and online, and both devices are signed in to the same Tailscale user. Check the Mac permissions if the video is blank or input does not respond. Changing between Wi-Fi and cellular can interrupt a session; the app attempts to reconnect. iPadOS may suspend a background app, so an uninterrupted background connection cannot be guaranteed.

두 기기의 로그인 계정, Mac의 잠자기 상태와 권한을 먼저 확인해 주세요. Wi-Fi·셀룰러 전환 중에는 연결이 잠시 끊길 수 있습니다. iPadOS가 앱을 중단하면 백그라운드 연결을 계속 유지할 수는 없습니다.
